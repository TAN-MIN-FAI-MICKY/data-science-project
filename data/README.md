# Dataset files

`day.csv` contains the daily bike rental records used by the notebook. It is from the [UCI Bike Sharing Dataset](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).

**Citation:** Fanaee-T, H. (2013). *Bike Sharing Dataset*. UCI Machine Learning Repository. https://doi.org/10.24432/C5W894

The dataset is available under the [Creative Commons Attribution 4.0 International (CC BY 4.0) license](https://creativecommons.org/licenses/by/4.0/). The notebook can download the source archive from UCI if `day.csv` is unavailable.
